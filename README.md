WeatherComrade is a weather companion web application built with ASP.NET Core MVC that combines real-time weather forecasting with a virtual assistant. The companion reacts to weather conditions, provides clothing and activity recommendations, and displays alerts using forecast data.

Cannout run without adding 
"AllowedHosts": "*",
  "WeatherApi": {
    "ApiKey": `YOUR API KEY`
  }
In appsetting.json

To run go to WeatherComrade.Api and use dotnet run
